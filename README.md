# Linux System Administration Lab

Repositorio personal de laboratorios prácticos enfocados en Administración de Sistemas Linux.
El objetivo de este proyecto es documentar prácticas reales, procedimientos de troubleshooting y ejercicios de administración de sistemas para fortalecer habilidades técnicas en entornos Linux


## Tecnologías y Herramientas 
- Linux
- Ubuntu
- CentOS
- OpenSSH
- Git
- GitHub
- Visual Studio Code
- MobaXterm


---

## Objetivos de Aprendizaje

- Administración de usuarios y grupos.
- Gestión de permisos y seguridad.
- Troubleshooting de conectividad.
- Automatización mediante scripts.
- Monitoreo y administración de sistemas Linux
